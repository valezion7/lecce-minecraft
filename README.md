# Lecce Minecraft

Tutta la città di Lecce ricostruita in **Minecraft Java Edition**, da scaricare gratis.
Strade, piazze, chiese ed edifici sono generati dai dati di OpenStreetMap e rifiniti a mano da Studio Beezy.

Pagina del progetto: **https://www.studiobeezy.com/lecce-minecraft**

## Download

- Diretto: https://download.studiobeezy.com/LecceMinecraft_v16.zip
- Oppure dalla [release v16](https://github.com/valezion7/lecce-minecraft/releases/tag/v16) di questo repository.

File `LecceMinecraft_v16.zip`, 1.222.686.195 byte (circa 1,2 GB; estratto circa 4 GB).
SHA-256: `7470739f9ebe47af1119c8e08ab1e2d45b248bd9dd8159be5db4810ec722ecd2`

## Installazione

Versione del gioco: **Minecraft Java Edition 26.3** (con versioni precedenti il mondo non si apre).

1. Estrai lo zip: ottieni la cartella `Lecce Minecraft`.
2. Copia la cartella `Lecce Minecraft` (intera, non solo il contenuto) nella cartella dei salvataggi:
   - **Windows:** `%appdata%\.minecraft\saves` (Win+R, scrivi il percorso e premi Invio)
   - **macOS:** `~/Library/Application Support/minecraft/saves`
   - **Linux:** `~/.minecraft/saves`
3. Avvia Minecraft 26.3 > Giocatore singolo > "Lecce Minecraft - Studio Beezy (v16)".

Al primo ingresso nasci in Piazza Sant'Oronzo. Il primo caricamento può durare un po': il mondo prepara il memoriale e il pannello della mappa.

**Memoria (RAM):** il mondo è grande. Nel launcher, in Installazioni > Modifica > Altre opzioni, assegna 4-6 GB a Java (es. `-Xmx6G` al posto di `-Xmx2G`).

**Shader (facoltativi):** per luci e ombre realistiche installa Fabric + Sodium + Iris e uno shader pack a scelta. Il mondo funziona anche senza.

**Altre piattaforme:** versione Bedrock / console in arrivo sabato. La mappa è ancora in aggiornamento: le nuove versioni escono qui e sulla pagina del progetto.
